# Project Godot Environment

## Prerequisites

- Python 3.8+
- Git
- OpenAI API Key

## Quick Setup

### 1. Clone Repository

```bash
git clone <your-repo-url>
cd Project-Loki
```

### 2. Environment Configuration

Create `.env` file in the **root directory** (not in subfolder):

```
OPENAI_API_KEY=sk-your-openai-key-here
```

## Project Structure

```
Project-Loki/
├── .env                    # Environment variables
├── .gitignore             # Git ignore rules
└── godot/
```

## Development Notes

- Make sure your `.env` file is in the project root directory
